# ReaWebAPI

- 新增最终视频帧尺寸查询，以及原始、窗口适配和自定义输出模式，明确处理像素预算超限与共享配置冲突。
- 视频 RGBA 单帧支持至 40 MiB，覆盖 UHD/DCI 4K，限制传输缓存占用，支持双线性缩放与完整分辨率预览绘制。
- Windows、macOS 及支持全屏的 Linux 窗口管理器新增原生元素全屏支持。
- 更新视频 Demo，提供自动预览、统一选项菜单、深浅主题、EN/CN 切换、全屏与宽高比开关、原始像素大小、空格播放控制，以及独立尺寸与帧率诊断。
- 通过 Windows 工作线程直收、Linux 原生内存及 macOS 本地资源减少视频复制，新增 Windows x64、macOS ARM64 和 Linux x86_64 已验证 BT.709 转换器的可选原始 I420 输出与 GPU 转换，保留原始纹理并按实际显示像素绘制，支持视频窗口按需关闭 macOS WebKit 接近 60 Hz 的调度偏好，修复 Windows 退出全屏后的浮动窗口归属。
- 修复宿主重复播放位置追赶音频时钟时被误判为跳转而清屏的问题，采集耗时按完成帧统计，避免被空轮询覆盖。
- 使用相邻缓存帧对应的视频源标识进行校验，避免异步解码时误拒绝有效帧。
- 修复慢视频套接字消费者拖停其他预览的问题，按实际容量限制发送池并预留帧发布空间。
- 修复视频队列并发发布时后帧越过前帧的问题，避免缓冲区未溢出时仍静默漏帧。
- 新增 Windows D3D11 与 macOS Metal 原生视频呈现，多窗口共享帧上传与 RGB 转换，保留 HTML 控件和现有像素流。
