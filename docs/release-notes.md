# ReaWebAPI

## English

- Fix macOS and Linux floating Docker title bars not following the active WebView's icon and visibility. Restore the container's original icon state when switching tabs, undocking or closing.

## 简体中文

- 修复 macOS 和 Linux 浮动 Docker 标题栏未跟随当前 WebView 图标及显示设置的问题。切换标签、取消停靠或关闭后还原容器原有图标状态。
