# Web 运行能力检查

[English](README.md) | **简体中文**

配合当前 ReaWebAPI 扩展使用的浏览器能力检查示例。保留完整目录，在 REAPER 中运行 `Open.lua`。

页面检查模块、本地 JSON 加载、存储、Canvas 和 Worker。重新打开可验证访问计数持久化，复制到另一目录可检查 localStorage 和 IndexedDB 隔离，cookie 计数在同一主机的 App 之间共享。将系统文件或文本拖入指定区域可检查系统集成，动画检查期间保持窗口可见。

结果按必需和可选浏览器能力显示。平台行为和存储路径见 [Web 运行环境](../../docs/frontend.zh-CN.md)。
