# SVG 覆盖层

[English](README.md)

需要 ReaWebAPI v0.3.9.26 或更高版本。在 REAPER 中运行 `reawebapi-overlay.lua`。每次加载默认使用英文，通过紧凑的 **EN** / **CN** 按钮切换语言。

面板保持居中。初始窗口适配英文面板，上下左右各留 24 CSS 像素，并限制在显示器工作区内。装饰边框贴合原生窗口边缘。

## 操作

- 纵向拖动 SVG 旋钮调整工程的主音量和声像，按住 Shift 可精细调整。拖动时隐藏鼠标，松开后回到起始位置。Esc 或窗口失焦会结束手势，保留已调整的参数。
- **局部交互**仅由控件接收鼠标输入，其余区域穿透至 REAPER。
- **窗口交互（移动 / 缩放）**保持背景透明，由整个窗口接收输入。拖动非控件区域移动窗口，拖动原生边缘或角落调整大小。控件保留自身交互，REAPER 浮动窗口在所有模式下仍位于覆盖层上方。
- **纯装饰（全部穿透）**不接收鼠标输入。使用前，将 `restore-interaction.lua` 和 `close-overlay.lua` 注册为 REAPER 操作，以便恢复交互或关闭。
- 右上角 **×** 关闭窗口。**背景不透明度**仅调节面板背景（0–100%，默认 40%），局部交互模式下也可操作。文字、控件和外围装饰保持不变。
- **铺满显示器**重新应用当前显示器边界。
- **将快捷键路由至 REAPER Main**将非编辑区域的受支持按键交给 Main 绑定。编辑区域保留文字和 IME 输入，不保证转发系统、浏览器保留快捷键及任意国际键盘布局。

## 实现

`index.html` 集中包含 HTML、标记清晰的 CSS 区块和 JavaScript 模块。模块划分为语言、SVG 命中区域、窗口策略、参数手势和清理部分，不依赖单独的 JS、CSS 文件或构建步骤。

`mouseRegions()` 按 1 CSS 像素精度采样 SVG 填充和描边，并合并为矩形。普通 DOM 控件使用包围矩形。布局、窗口大小、滚动和语言变化后更新区域。每个 SVG 的采样上限为 1,048,576 CSS 像素。自定义动画、样式、裁剪、遮罩和非缩放描边需要 App 自行维护区域。

窗口交互模式在 body 上启用既有的 `data-reaweb-drag` 契约，按钮、输入框和 SVG 滑块通过原生排除规则保留交互。其他鼠标模式移除拖动区域，边缘缩放复用宿主的无边框窗口能力。

鼠标手势使用浏览器 Pointer Lock API 和相对位移，释放、取消和清理时退出锁定。锁定被拒绝时显示错误，不开始参数调整。触摸和笔输入使用指针捕获。macOS 和 Linux 仅对独立覆盖层窗口授权指针锁定。

## 平台条件

- **Windows**：需要支持原生拖动区域和透明窗口的 WebView2 Runtime。
- **macOS**：启动示例前，打开**系统设置 → 隐私与安全性 → 辅助功能**，开启 **REAPER**。列表中没有 REAPER 时，点击 **＋** 添加实际使用的 REAPER 应用。授权后退出并重新打开 REAPER。原生鼠标路由不会自动弹出授权请求。
- **Linux**：需要原生 X11、X Shape、XInput、支持透明窗口的合成器及兼容窗口管理器，不支持 Wayland／XWayland。铺满显示器时向屏幕底部外侧多铺 1 个原生像素，避免窗口被自动提升到全屏层，修改示例时需保留此处理。原生移动和缩放还要求窗口管理器支持 `_NET_WM_MOVERESIZE`。

接口行为、能力和错误见[覆盖层契约](../../../docs/window-overlay.zh-CN.md)。
